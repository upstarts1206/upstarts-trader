# Upstarts Trader

A modular trading research platform designed to help traders build,
test, compare, and improve trading strategies using objective data.

The goal is not to automate trading blindly.

The goal is to improve decision making through:

- Market Analysis
- Market Structure
- Smart Money Concepts
- Configurable Strategies
- Risk Management
- Backtesting
- Performance Analytics
- AI-assisted Trade Review

Every trading concept should be:

- Configurable
- Testable
- Comparable

Every trading signal should include:

- Confidence
- Risk Assessment
- Position Sizing
- Trade Plan

# Milestone 7 — Scanner & Alert Engine

Goal

Transform Upstarts Trader from a manual analysis tool into an active trading assistant.

Features

- Multi-symbol scanning
- Watchlist management
- Automatic market analysis
- Scheduled scanning
- Candle-close event detection
- Alert Engine
- Discord notifications
- Telegram notifications
- Desktop notifications
- Notification history

Success Criteria

The application continuously monitors configured markets and notifies the user only when predefined trading conditions are met.
