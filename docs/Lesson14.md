# Lesson 14 - Break of Structure

## Objective

Detect bullish Breaks of Structure using confirmed Swing Highs.

---

## Definition

A BOS occurs when price closes above the most recent confirmed Swing High.

---

## Process

1. Detect Swing High.
2. Store the Swing High.
3. Wait for price to close above it.
4. Mark BOS.
5. Reset and wait for the next Swing High.

---

## Notes

Current implementation supports bullish BOS only.

Bearish BOS will be implemented later.
