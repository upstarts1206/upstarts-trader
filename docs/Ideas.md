# Active Trading Assistant

Vision

The application should continue monitoring markets even when the user is away.

Instead of manually opening the application and requesting an analysis, Upstarts Trader should continuously monitor configured markets and notify the user only when predefined trading conditions are satisfied.

Potential Notification Channels

- Discord
- Telegram
- Desktop Notifications
- Email

Core Principle

The user should only be interrupted when a high-quality trading opportunity is detected.
