# Lesson 19 - Configuration

## Objective

Centralize configurable values.

---

## Why

Avoid magic numbers throughout the project.

Changing a setting should not require searching the codebase.

---

## Examples

- Symbol
- EMA Periods
- Swing Lookback
- Default Risk
- BOS Method

---

## Benefits

- Easier maintenance
- Easier experimentation
- Easier testing
- Cleaner code
