# Lesson 22 - Multi-Timeframe Foundation

## Objective

Prepare the architecture for analyzing multiple timeframes.

---

## Why?

Professional traders rarely make decisions using only one timeframe.

Different timeframes answer different questions.

15m -> Entry

1H -> Trend

4H -> Market Structure

---

## Current Limitation

Only one timeframe is analyzed.

Future lessons will populate MarketContext with multiple datasets.

---

## Key Takeaway

MarketContext should represent the complete market, not just one chart.
