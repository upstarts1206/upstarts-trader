# Lesson 32 - Decision Engine

## Objective

Create a dedicated engine that converts market analysis into a trading recommendation.

---

## Decision Levels

- BUY
- WAIT
- SKIP

---

## Current Decision Criteria

- Trend direction
- Trading signal
- Risk / Reward validation

---

## Why?

Analysis alone is not actionable.

The Decision Engine combines multiple analysis modules into a single recommendation with transparent reasoning.

---

## Future Improvements

- Weighted scoring
- Strategy-specific rules
- Session awareness
- Multi-timeframe confirmation
- News filter
- Volatility filter
- User-defined decision rules

---

## Key Takeaway

A trading assistant should explain *why* it recommends an action, not just *what* the action is.
