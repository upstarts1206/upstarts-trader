# Lesson 30 - Dynamic Take Profit

## Objective

Calculate a take-profit target using market structure instead of a fixed percentage.

---

## Current Method

- Find the nearest Swing High above the current price.
- If none exists, use a default 3% target.

---

## Why?

Swing highs often act as natural resistance levels where traders may take profits.

Using market structure creates more logical targets than arbitrary percentages.

---

## Future Improvements

- Liquidity targets
- Order Block targets
- Fair Value Gap targets
- Multi-target exits
- Partial take profit
- Dynamic trailing exits

---

## Key Takeaway

Take-profit targets should be based on where the market is likely to react, not on arbitrary percentages.
