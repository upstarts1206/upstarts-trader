# Lesson 29 - Dynamic Stop Loss

## Objective

Calculate a stop loss using market structure instead of a fixed percentage.

---

## Current Method

Use the latest confirmed Swing Low.

Apply a small buffer below the swing.

---

## Why?

Market structure provides more logical invalidation points than arbitrary percentages.

---

## Future Improvements

- ATR buffer
- Order Block stop
- FVG stop
- Volatility-adjusted stop
- Multi-timeframe stop selection

---

## Key Takeaway

A stop loss should invalidate your trade idea, not simply satisfy a percentage.
