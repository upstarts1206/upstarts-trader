# Lesson 54 - Alert Manager

## Objective

Prevent duplicate notifications by remembering previously reported trade opportunities.

---

## Architecture

Automation Runner

↓

Alert Manager

↓

Presentation / Notifications

---

## Why?

Automation should notify users only when meaningful changes occur.

---

## Current Features

- First-time alerts
- Decision change detection
- Confidence improvement detection

---

## Future Improvements

- Alert expiration
- Cooldown periods
- Strategy-aware alerts
- Multi-channel routing

---

## Key Takeaway

Notifications should represent new information rather than repeating the same signal.
