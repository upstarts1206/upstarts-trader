# Lesson 20 - Change of Character (CHOCH)

## Objective

Detect basic bearish Change of Character events.

---

## Definition

A bearish CHOCH occurs when price closes below the latest confirmed Swing Low.

---

## Current Limitation

The current implementation does not consider the previous trend.

Future lessons will make CHOCH trend-aware.

---

## Why?

CHOCH is not just a break.

It is a break that changes market behavior.
