# Lesson 25 - Order Blocks

## Objective

Detect the last opposing candle before a market structure break.

---

## Bullish Order Block

The last bearish candle before a Bullish BOS.

---

## Bearish Order Block

The last bullish candle before a Bearish CHOCH.

---

## Current Scope

This implementation is intentionally simple.

Future versions will include:

- Mitigation
- Zone refinement
- Volume confirmation
- Institutional displacement
- Multi-timeframe validation

---

## Key Takeaway

An Order Block is not just a candle.

It represents the area where significant buying or selling likely originated.
